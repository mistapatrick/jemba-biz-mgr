JEMBA BUSINESS MANAGER - START HERE

1. Install Node.js 20.9+ and npm.
2. Open a terminal in this project folder.
3. Run: npm install
4. Copy .env.example to .env.local and add Supabase URL + anon key + service-role key.
5. Run: npx supabase login
6. Run: npx supabase link --project-ref YOUR_PROJECT_REF
7. Run: npx supabase db push
8. Run the owner bootstrap command shown in DEPLOYMENT_COMMANDS.md.
9. Run: npm run dev
10. Open http://localhost:3000

Do not commit .env.local. Do not expose the service-role key in browser code.
See README.md and docs/IMPLEMENTED_AND_PENDING.md for limitations and release gates.
